# pi-meguru

[English](README.md) | 简体中文

为 Pi codemode 提供轻量级 DAG 编排。

## 安装

需要先在 Pi 内启用 `codemode` 工具，此插件才会生效。

```sh
pi install npm:pi-meguru
```

## 工作原理

一次 PTC 分成三个区域，用普通 JavaScript 描述：

| 区域 | 定义 |
| ---- | ---- |
| **`graph`**：| 声明节点和它们间的连接方式。图必须是一个 DAG，且只能有一个起点；每次沿一条路径执行，不并行展开分支。|
| **`actions`**：| 定义每个节点做什么。一个节点就是一次标准 codemode，返回值作为该节点的输出，通过只读的 `ctx.<节点名>` 供后续节点读取。|
| **`guards`**：| 用同步 JS 表达式决定走哪条边。多条出边按顺序检查，第一个条件成立的分支胜出，`ELSE` 作为最后的兜底分支。|

脚本调用 `flow()` 时，扩展把运行时追加到脚本末尾，一起交给 codemode 的 QuickJS 执行，工具调用沿用 Pi 原有的权限和 hook。

`watch` 和 `break` 决定模型何时看到执行现场：

- **Watchpoint**：每个节点完成后计算观察表达式，只记录变化，不打断执行。记录随 `flow()` 的结果返回，模型在本次 PTC 返回后查看。
- **Breakpoint**：在节点执行前检查条件，命中就保存进度并返回 `paused`。本次 codemode 脚本结束后，控制权回到模型，由模型决定如何继续。断点条件必须同步，同一个节点的断点在一次运行中只停一次。

节点出错或没有可选分支时，也会保存进度并返回错误。`flow()` 本身只返回数据，不自动打印结果。
